# @openwa/api

Elysia-based REST API deployed to Cloudflare Workers. Provides session management, messaging, webhook CRUD, and authentication endpoints.

**Status (Sprint 1):** Hello-world stub. Real endpoints land in Sprint 3 (`US-021`–`US-032`).

## Dev

```bash
bun run dev      # wrangler dev (local)
bun run deploy   # wrangler deploy (default env)
```
